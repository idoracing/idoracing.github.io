IdoRacing Launcher y Sistema de Configuración

idoracing-launcher es el supervisor central nativo en Go encargado de orquestar todos los componentes de pista (grabador, HUD de pedales, spotter de radio y luces de volante Moza) con un único proceso ligero.

Los 4 Subsistemas del Launcher

pep_spotter Activo por defecto

Spotter de pista que reproduce clips de radio offline a 250m de curva. Informa de deltas de frenada, velocidad de vértice y advertencias de presiones de neumáticos.

hud_overlay Activo por defecto

Ventana nativa transparente en X11/Win32 que proyecta el osciloscopio de pedales y el indicador visual de trail braking en tiempo real sobre el juego.

moza_shift_lights Activo por defecto

Conexión CDC-ACM directa con bases Moza (R5, R9, R12, R16, R21) en Linux para encender la tira de LEDs de RPM y destello de cambio sin necesidad de Pit House.

recorder Activo por defecto

Grabador binario a 50Hz que captura las vueltas completas y almacena la física en archivos CSV/SQLite sin interferir con el hilo de renderizado del simulador.

Archivo de Configuración: idoracing-launcher.json

100% retrocompatible

El launcher busca automáticamente su archivo de configuración en un orden jerárquico estricto:

  1. Directorio actual de ejecución (./idoracing-launcher.json)
  2. Subdirectorio de datos (data/idoracing-launcher.json)
  3. Directorio de configuración del usuario (~/.config/idoracing/ en Linux o %APPDATA%\idoracing\ en Windows)
  4. Modo a prueba de fallos: Si no existe ningún archivo, arranca con valores por defecto seguros en memoria sin fallar ni corromper nada.
idoracing-launcher.json JSON 
{
  "subsystems": {
    "pep_spotter": true,
    "hud_overlay": true,
    "moza_shift_lights": true,
    "recorder": true
  },
  "hotkeys": {
    "spotter_mute": "KeyM"
  },
  "audio": {
    "volume": 85,
    "language": "es"
  }
}

Parámetros por Terminal (Overrides de Sesión)

Puedes anular cualquier subsistema temporalmente para una sesión concreta sin necesidad de editar el archivo JSON:

Flag CLI Efecto Ejemplo de uso
-no-hud Desactiva el overlay visual en pantalla (modo inmersivo) idoracing-launcher -no-hud
-no-spotter Silencia por completo la radio de Pep durante la tanda idoracing-launcher -no-spotter
-no-moza Desactiva el puente USB serie de luces Moza idoracing-launcher -no-moza
-no-recorder Corre solo con HUD y luces sin escribir telemetría a disco idoracing-launcher -no-recorder
-status Muestra un informe de diagnóstico y cierra de inmediato idoracing-launcher -status
// INTEGRACIÓN CON STEAM ·

Arranque Automático al pulsar "Jugar" en Steam

El launcher está diseñado para colocarse directamente en las Opciones de Lanzamiento de Steam. Cuando pulsas "Jugar" a Assetto Corsa Competizione o Le Mans Ultimate, Steam arranca primero el launcher y este ejecuta el juego limpiamente:

En Linux (Proton):
gamemoderun ~/.local/bin/idoracing-launcher %command%
En Windows:
"C:\Ruta\A\IdoRacing\idoracing-launcher.exe" %command%
